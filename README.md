# My Portfolio Website

A modern, responsive portfolio website built with HTML, CSS, and JavaScript.

## Features
- Responsive design (mobile, tablet, desktop)
- Smooth scroll navigation
- Typing animation effect
- Scroll reveal animations
- Contact form with validation
- Mobile hamburger menu
- Dark theme with gradient accents

## How to Deploy for FREE

### Option 1: GitHub Pages (Recommended - Free `.github.io` domain)

1. **Create a GitHub account** at https://github.com (if you don't have one)
2. **Create a new repository** named `yourusername.github.io`
3. **Upload your files:**
   - Go to your new repository
   - Click "Add file" > "Upload files"
   - Drag and drop `index.html`, `style.css`, and `script.js`
   - Click "Commit changes"
4. **Your site is live** at `https://yourusername.github.io`

### Option 2: Netlify (Free `.netlify.app` domain)

1. Go to https://www.netlify.com and sign up (free)
2. Click "Add new site" > "Deploy manually"
3. Drag and drop the entire `portfolio` folder
4. Your site is instantly live at a random `.netlify.app` URL
5. You can customize the subdomain in Site Settings

### Option 3: Vercel (Free `.vercel.app` domain)

1. Go to https://vercel.com and sign up (free)
2. Click "New Project" > "Import Git Repository" or upload directly
3. Your site deploys automatically

### Option 4: InfinityFree (Free custom `.epizy.com` or `.rf.gd` domain)

1. Go to https://www.infinityfree.com and sign up
2. Create a new hosting account
3. Upload files via File Manager or FTP
4. Get a free subdomain like `yourname.epizy.com`

## Customization

Replace the placeholder content:
- **"Your Name"** - Your actual name
- **"your.email@example.com"** - Your email
- **Social links** - Your GitHub, LinkedIn, Twitter URLs
- **Projects** - Your real projects with links
- **Skills** - Adjust skill percentages
- **About section** - Your bio and stats
- **Profile image** - Replace the placeholder with your photo

## Tech Stack
- HTML5
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (No frameworks needed)
- Font Awesome Icons
- Google Fonts (Inter)
